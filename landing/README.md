# Page de liste d'attente : mise en ligne

## 1. Brancher le formulaire (5 min, gratuit)
1. Crée un compte sur [formspree.io](https://formspree.io). Le plan gratuit accepte un nombre limité d'envois par mois ; vérifie la limite actuelle sur leur site.
2. Crée un formulaire et copie son URL (`https://formspree.io/f/xxxxxxx`).
3. Dans `index.html`, colle-la dans `const FORM_ENDPOINT = "";`.
4. Fais un test d'inscription. Le premier envoi demande une confirmation par email côté Formspree.

## 2. Héberger la page (gratuit)
- **Netlify Drop** (le plus simple) : glisse le dossier `landing/` sur [app.netlify.com/drop](https://app.netlify.com/drop). Tu obtiens une URL publique en 1 minute.
- Autres options : GitHub Pages (si le dépôt est public) ou Cloudflare Pages.
- Mets cette URL dans la bio TikTok et Instagram (ou via un « link in bio »).

## 3. Avant la mise en ligne (obligatoire)
- [ ] Remplir les `[CROCHETS]` de `confidentialite.html` (responsable, contact, encadrement du transfert hors UE par Formspree).
- [ ] Ajouter les **mentions légales** dans le pied de page (éditeur, hébergeur), obligatoires en France pour un site.
- [ ] Vérifier que le nom « Réplique » est libre (App Store, INPI, comptes sociaux). Sinon, on le remplace partout.
- [ ] Si tu promets « 1 mois offert » dans les vidéos, le mentionner sur la page.

## 4. Mesurer
Formspree compte les inscriptions. Note chaque jour le total à côté des vues TikTok dans ton tableau de suivi. Objectif go/no-go à J14 : **plus de 100 inscrits** ou **plus de 50 k vues cumulées**.
